#### **Level 3 : Imporvement & Bugs (AI Assisted)**

### **Objective**

To practice **brownfield development at Level 3**, where participants solve **complex bugs** and implement **advanced improvements** in an existing system. They will use **Cursor IDE’s AI-driven refactoring, architectural suggestions, and testing support** to handle issues that require **cross-module changes, performance optimization, or system-level fixes**.

### **Requirements**

* Cursor IDE connected with the repo.  
* Repo branches provided:  
  * level-2-complete (base branch for this activity).  
  * bug-l3-\* and improvement-l3-\* (reference solutions).  
  * level-3-complete (validation branch).  
* Scope of **L3 improvements & bugs**:  
  * **Improvements** → architectural-level or systemic changes (e.g., migrating to async APIs, adding caching strategies, redesigning schema, improving security).  
  * **Bugs** → critical issues with high complexity (e.g., memory leaks, deadlocks, concurrency handling, incorrect business logic spanning modules).

### **Steps**

**1\. Setup & Contextualize**

* Checkout level-2-complete.  
* Open in Cursor IDE and create a new branch feature-l3-advanced.  
* Use Cursor’s **project overview prompt**:  
  * Generate a system-level summary of dependencies, modules, and known issues.

**2\. Deep-Dive Analysis**

* Pick one **L3 bug** and one **L3 improvement**.  
* Use Cursor’s AI to:  
  * Trace code flow across multiple files.  
  * Suggest potential architectural weak points.  
  * Draft a **multi-step plan** for the fix/improvement.

**3\. Resolve Complex Bugs**

* Use Cursor IDE’s **“find root cause”** and **inline debugging suggestions**.  
* Apply AI-suggested changes but validate manually through reasoning.

**4\. Implement Advanced Improvements**

* Work with Cursor’s **“generate refactor”** to restructure code.  
* AI generates code snippets, devs refine and test integration.

**5\. Validation**

* Compare with level-3-complete for validation.

**6\. Version Control & Delivery**

* Commit changes in a **modular fashion** (fix: prevent deadlock in job queue, improvement: async migration for API).  
* Push to GitHub and open PR.  
* Document **what was fixed and how Cursor helped** in the PR description.

### **Expected Outcome**

* Participants resolve **critical, system-wide bugs** and implement **architectural improvements**.  
* Demonstrated advanced usage of **Cursor IDE**:  
  * System-level analysis.  
  * AI-driven refactoring.  
* Final repo matches level-3-complete.
